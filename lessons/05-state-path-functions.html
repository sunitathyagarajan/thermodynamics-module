Lesson 5

State functions vs path functions

Some quantities care only about where you are. Others care about how you got there. Knowing which is which explains why we write ΔU but never "Δq" — and why the first law is so useful.

In this lesson

  • Define state functions and path functions, and give examples of each.
  • Use an interactive P–V diagram to see that ΔU stays fixed while q and w change with the path.
  • Explain why internal energy is a state function.
  • Explain why heat and work are path functions.
  • See what happens to each kind of quantity around a closed cycle.

The two kinds of quantities

State function

A property whose value depends only on the present state of the system (its P, V, T, amount and composition) — not on its history.

  • The change depends only on the start and the end: ΔX = Xfinal − Xinitial.
  • Around any closed loop (back to the start), ΔX = 0.

Examples: P, V, T, n, density, internal energy U, enthalpy H, entropy S.

Path function

A quantity whose value depends on the route taken between two states. It describes a process, not a state.

  • It has no value "at" a state, so there is nothing to subtract: we write q and w, never Δq or Δw.
  • Around a closed loop it is usually not zero.

Examples: heat q, work w (and, on a trip, distance travelled or fuel used).

How are these numbers calculated?

For a monatomic ideal gas, U = 3⁄2nRT = 3⁄2PV, so U is fixed by the point you're at: UA = 1.5 × 2.00 × 10.0 = 30.0 L·atm and UB = 1.5 × 1.00 × 30.0 = 45.0 L·atm, giving ΔU = 15.0 L·atm = +1520 J for every path. The work is w = −(area under the path), each straight segment being a trapezoid: w = −½(Pstart + Pend)ΔV. The heat then follows from the first law: q = ΔU − w. (The gas pushes on a piston with Pext = Pgas the whole way.)

What the tool shows
  • ΔU = +1520 J and ΔT = +122 K for every path — because they depend only on the points A and B.
  • w changes with every move of C, because the area under the path changes.
  • q changes too, in exactly the opposite way, so that q + w always comes back to the same ΔU.

Why internal energy is a state function

Reason 1 — U is something the system has

Internal energy is the total kinetic and potential energy of all the particles in the system (Lesson 3). Once the state is fixed — the temperature, pressure, volume, amount and composition — the particles' motions and the forces between them are fixed too, and so is their total energy. Like mass or volume, U is a property of the system in that state. The system doesn't "remember" how it got there.

Reason 2 — if it weren't, we could create energy from nothing

Suppose ΔU for A → B were different along two paths, say +1520 J along path 1 and only +1000 J along path 2. Then we could take the gas from A to B along path 2 and bring it back along path 1. The gas ends exactly where it started, yet we'd have 520 J left over, every cycle, forever — a perpetual-motion machine. That would break conservation of energy. So the first law requires ΔU to be the same for every path.

Why heat and work are path functions

Reason 1 — they are energy in transit, not energy stored

Heat and work only exist while energy is crossing the boundary. Once the energy is inside, it is simply internal energy; there is no "heat content" or "work content" left in the system to measure. A system in state B cannot tell you how much of its energy arrived as heat and how much as work — just as a pond can't tell you how much of its water fell as rain.

Reason 2 — work is an area, and different paths have different areas

For pressure–volume work, w = −(area under the path on a P–V diagram). Two paths between the same points generally enclose different areas, so they do different amounts of work — exactly what you saw in the interactive tool:

Reason 3 — the first law then forces q to depend on the path too

The first law says q = ΔU − w. ΔU is fixed by the states, so whenever w changes, q must change by the same amount in the other direction:

Around a closed loop

The clearest test of a state function: take the system around a loop and back to where it started. A state function must return to its original value; a path function need not.

Around any cycle ΔU = 0 (state function), but the size of the net w equals the area enclosed by the loop: w is negative for a clockwise loop like this one (net work done by the gas) and positive for a counterclockwise loop. Then q = −w, which is generally not zero. This is exactly how an engine works: it runs in a cycle, returns to its starting state every time, and turns net heat into net work.

Why this matters in chemistry

  • We can calculate ΔU (and ΔH) along any convenient path — even an imaginary one — and the answer applies to the real process. This is the idea behind Hess's law.
  • Special conditions turn heat into a state-function change. At constant volume, w = 0 so qV = ΔU; at constant pressure, qP = ΔH. That's why calorimeters (Lesson 4) measure state functions even though heat is a path function.
  • Reversible vs irreversible processes (Lesson 7) are two different paths between the same states — so they give different q and w but the same ΔU.
